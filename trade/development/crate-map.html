enums.rsDomain enums: Side, OrderType, TimeInForce, RejectReason, SessionState, etc.
commands.rsOrderCommand enum + NewOrderFields, CancelFields, ReplaceFields, OrderStatusReport
events.rsExchangeEvent enum (19 variants) + SequencedEvent
instrument.rsInstrumentConfig, SessionConfig, SettlementConfig, InstrumentRegistry trait
participant.rsParticipantConfig, LatencyProfile, ParticipantRegistry trait

Key Cross-Cutting Rules

  • SimClock for all business time. tokio::time::sleep, Instant::now, and chrono::Utc::now are forbidden in business code. Only allowed in: SimClock impls, gateway heartbeats, metrics, DB batching.

  • No unwrap/expect/panic! outside tests and main.rs. The matching engine must never panic on malformed input — reject instead.

  • Determinism. No HashMap iteration in hot paths — use BTreeMap. No RNG in matching core.

  • Decimal serialization. Always JSON strings, never floats. Use rust_decimal + #[serde(with = "rust_decimal::decimal")] or serde-str.

  • Event sourcing. System state is reconstructed from the events table + snapshots. No mutable “current state” database.

  • Error handling. thiserror in library crates, anyhow only in binaries.

  • rust_decimal for Price/Qty — never f64 for money.
